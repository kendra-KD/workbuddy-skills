# 升级流程指引 · 什么时候该升级、升级到谁

> 问题上报不是终点，而是起点。这份指引帮你在合适的时间把问题升级到合适的人。

---

## 一、为什么要升级

问题上报后，不是"报完就完了"。以下情况需要主动升级：

1. **超时未响应**：按紧急度的响应预期，超时了还没人接手
2. **超出你的能力范围**：你试过能试的，问题仍未解决
3. **影响扩大**：问题影响范围从局部扩散到全局
4. **客户施压**：VIP 客户/领导直接过问
5. **需要跨团队协作**：问题涉及多个团队/系统

---

## 二、升级时机（按紧急度）

| 紧急度 | 响应预期 | 升级触发条件 | 升级到谁 |
|--------|---------|------------|---------|
| 🔴 紧急 | 5 分钟内有人接手 | 10 分钟无人响应 / 30 分钟未定位根因 / 1 小时未恢复 | 直属领导 + 相关团队负责人 |
| 🟡 重要 | 30 分钟内响应 | 1 小时无人响应 / 2 小时未定位 / 4 小时未恢复 | 直属领导 |
| 🟢 普通 | 当天响应 | 次日仍未处理 | 直属领导（周报同步） |

## 三、升级话术模板

### 场景 1：超时未响应

```
@领导 [问题上报] 紧急度 🔴，已上报 X 分钟，目前无人接手。
故障概况：[一句话描述]
影响：[一句话影响]
当前状态：[已做/未做]
请安排人接手。
```

### 场景 2：超出能力范围

```
@领导 [问题升级] 我已做以下排查但仍未解决：
已试操作：
1. [操作1] → [结果]
2. [操作2] → [结果]
卡在：[当前卡点]
需要：[需要谁/什么资源协助]
```

### 场景 3：影响扩大

```
@领导 [问题升级] 故障影响扩大：
原影响：[局部/小范围]
现影响：[全局/大范围]
已做：[已做的紧急处置]
需决策：[是否需要降级服务/切换备用/通知客户]
```

### 场景 4：跨团队协作

```
@团队A @团队B [跨团队问题] 
故障涉及：[A 团队的 XX 服务] + [B 团队的 YY 服务]
现象：[一句话]
A 团队已确认：[A 侧无异常/已排查]
需 B 团队协助：[具体需要 B 做什么]
```

## 四、升级前自检清单

升级前确认你已经做完了这些（避免被反问"这个你试过吗"）：

- [ ] **完整报错已收集**：不只是"报错了"，而是完整的错误信息+日志
- [ ] **复现步骤已整理**：能复现的写清楚步骤，不能复现的注明偶发
- [ ] **已试操作已记录**：做过什么、结果是什么，不能只写"试过了"
- [ ] **影响范围已评估**：多少人/多少服务受影响
- [ ] **时间线已梳理**：什么时候发现、什么时候做了什么操作
- [ ] **相关日志已截图/保存**：不只是口头描述，有证据

## 五、不同岗位的升级路径

### 运维工程师
```
你 → 直属 leader → 运维总监 → CTO
                → 研发团队（技术问题）
                → 安全团队（安全事件）
```

### 技术支持
```
你 → 技术支持主管 → 研发团队
                → 产品经理（需求类）
                → 客户成功（客户沟通）
```

### SRE
```
你 → SRE 主管 → 研发团队
             → 安全团队
             → 基础设施团队
```

### 私有化交付
```
你 → 交付项目经理 → 研发团队
                 → 算法团队（C/D 类定制）
                 → 产品团队（E 类评估）
                 → 硬件供应商（F 类）
```

## 六、升级后的跟进

升级≠甩锅。升级后你仍然要：

1. **主动同步进展**：每 30 分钟（紧急）/ 2 小时（重要）同步一次
2. **配合接手人**：提供你需要的信息、执行接手人的指令
3. **记录全程**：时间线、操作记录、决策点都要留痕
4. **参与复盘**：问题解决后参与复盘，沉淀经验

---

## 七、特殊情况

### 客户直接找你
- VIP 客户/领导直接找你 → 即使你处理不了，也要先响应"收到，正在处理"，然后立即上报
- 不要对客户说"这不是我的事" → 改说"我来协调相关人员处理"

### 非工作时间
- 🔴 紧急 → 电话/短信通知（不只是发消息）
- 🟡 重要 → 消息通知 + 第二天跟进
- 🟢 普通 → 工作时间处理

### 你不确定该不该升级
- **宁可升级，不可隐瞒**：不确定时先上报，让领导判断
- 但不要"狼来了"：每次小事都升级，会降低你的可信度
