# 上报模板库 · 各场景标准化模板

> 不同岗位/场景的问题上报模板。可直接复制使用，也可让 AI 自动套用。

---

## 模板 1 · 运维故障上报（通用）

适用：运维工程师向 leader/同事上报生产故障。

```markdown
## 问题上报

- **客户名**：[客户名 / 内部服务]
- **环境/节点**：[环境] / [IP 或主机名] / [namespace 或服务名]
- **完整报错**：[HTTP 状态码 + 错误消息 + 关键日志片段]
- **已试操作**：
  1. [做了什么] → [结果]
  2. [做了什么] → [结果]
- **复现步骤**：
  1. [步骤]
  2. [步骤]
- **紧急度**：🔴/🟡/🟢
- **建议下一步**：
  - [排查方向]
```

## 模板 2 · 技术支持转研发

适用：技术支持/客服把客户问题转交给研发团队。

```markdown
## 客户问题转交

### 客户信息
- **客户名**：[客户名]
- **联系人**：[客户对接人 + 联系方式]
- **客户级别**：VIP / 普通 / 试用

### 问题信息
- **环境**：[客户环境：生产/测试，版本号]
- **现象描述**：[客户原话 + 你的整理]
- **完整报错**：[截图/日志]
- **已试操作**：[你帮客户做过的排查]
- **复现步骤**：[能否稳定复现]
- **影响范围**：[多少用户受影响 / 多少功能不可用]

### 转交原因
- [为什么需要研发介入]
```

## 模板 3 · SRE 故障交接

适用：SRE 团队内部故障交接（换班/升级）。

```markdown
## 故障交接

### 故障概况
- **故障 ID**：[如 INC-20261031-001]
- **开始时间**：[检测到的时间]
- **当前状态**：排查中 / 已定位 / 修复中 / 已恢复 / 待观察
- **紧急度**：🔴/🟡/🟢

### 故障详情
- **影响服务**：[受影响的服务列表]
- **影响用户**：[用户量/百分比]
- **根因（如已知）**：[初步定位的根因]
- **已做操作**：
  1. [时间] [操作] → [结果]
  2. [时间] [操作] → [结果]

### 交接事项
- **待跟进**：[下一步计划]
- **注意事项**：[接班人需要知道的]
- **相关链接**：[监控面板/日志/工单链接]
```

## 模板 4 · 私有化交付报障

适用：私有化交付过程中向原厂/研发报障。

```markdown
## 私有化报障

### 客户信息
- **客户名**：[客户名]
- **交付阶段**：部署中 / 验收中 / 已上线
- **服务器信息**：[IP / 配置 / OS 版本]

### 问题信息
- **涉及模块**：[标注平台 / MaaS / MinIO / 其他]
- **完整报错**：[报错日志]
- **环境信息**：
  - 版本：[组件版本号]
  - 配置：[相关配置项]
- **已试操作**：[排查过程]
- **复现步骤**：[步骤]

### 定制分类（A-F）
- **分类**：[A/B/C/D/E/F]
  - A=标准配置
  - B=标准配置（需调整参数）
  - C=需算法团队介入
  - D=需算法团队定制
  - E=需产品评估
  - F=硬件相关（先确认型号）
```

## 模板 5 · 安全事件上报

适用：安全相关事件上报（如证书过期、异常访问、数据泄露疑似）。

```markdown
## 安全事件上报

- **事件类型**：[证书过期 / 异常访问 / 疑似泄露 / 漏洞利用 / 其他]
- **发现时间**：[时间]
- **环境/节点**：[受影响的环境]
- **现象描述**：[详细描述]
- **影响评估**：
  - 数据影响：[是否涉及敏感数据]
  - 服务影响：[是否影响业务运行]
  - 用户影响：[是否影响用户]
- **已处置**：[紧急处置措施]
- **紧急度**：🔴/🟡/🟢
- **需协助**：[需要安全团队/法务/管理层做什么]
```

|---------|---------|
