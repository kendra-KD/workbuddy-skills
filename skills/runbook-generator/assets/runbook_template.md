# 空白 Runbook 模板

> 复制本模板，填入排查步骤，接入到 runbook_lib.py 的 RUNBOOKS 列表。

---

## 故障标题

**故障概述**：什么情况、什么现象、常见根因。

### 根因假设树

| # | 可能原因 | 验证方法 | 概率 |
|---|---------|---------|------|
| 1 | 原因 A | 怎么验证 | 🔴 高 |
| 2 | 原因 B | 怎么验证 | 🟡 中 |
| 3 | 原因 C | 怎么验证 | 🟢 低 |

```bash
具体命令
```

**预期输出**：正常情况下的输出。

**判断**：根据输出怎么判断下一步。

#### Step 2 · ...

```bash
具体命令
```

**预期输出**：...

**判断**：...

### 验证故障是否解决

怎么确认故障已解决（连续验证方法）。

### 回退方案

```bash
回退命令
```

## 填写检查清单

- [ ] id 唯一且为小写+连字符
- [ ] keywords 覆盖中英文，≥3 个
- [ ] root_causes 按概率排序，每条含 verify
- [ ] steps 每步含 action/command/expected/judgment
- [ ] command 可直接复制（占位符用 `<>` 标注）
- [ ] verify 有明确的验证方法
- [ ] rollback 覆盖有副作用的操作
